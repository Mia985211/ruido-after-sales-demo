瑞多售后服务 · 用户端需求文档 V2

方案 B · V3.4 | 2026-10-12 | 适用主体:上海荣泰健康科技股份有限公司 / 上海一诺康品电子商务有限公司 / 上海艾荣达健身科技股份有限公司(品牌摩摩哒)

一、产品概述

为用户提供移动端自助售后入口,实现三个目标:

  • 服务申请线上化:自助提交维修(设备报修)与移机申请,减少人工客服介入;
  • 收费透明化:收费标准、配件价格公开可查,降低费用纠纷;
  • 全程可追踪:报修记录与处理详情可查询,提升服务体验。

二、功能架构

  • 服务申请 → 维修服务(设备报修页:我要报修 / 报修记录)、移机服务
  • 维修记录 → 设备报修页,默认停在「报修记录」标签
  • 自助查询 → 收费标准(维修/移机)、配件价格

维修申请与维修记录共用一个页面,通过标签切换,两个入口只是默认标签不同,降低用户理解成本。

三、页面需求

3.1 设备报修(我要报修)

字段必填说明
SN码是手动输入或扫设备二维码
设备型号是手动输入或扫码带出
姓名 / 手机号码是报修联系人,手机号格式校验
区域选择是省 / 市 / 区三级联动
详细地址是门牌号等
问题描述是上限 200 字,实时字数
附件否最多 3 张,视频不超过 1 分钟

提交后生成维修工单,进入后台流程:客服核实 → 系统按区域自动分配服务商 → 服务商承接 → 上门履约 → 完成。

3.2 报修记录

按提交时间倒序展示历史报修单;卡片字段:型号、SN、提交时间、姓名、手机号码(脱敏)、维修地址、问题描述、附件;点击进入详情及处理状态。

3.3 移机服务

提示条「有偿服务:产生的上门费、配件费将由您承担」,右上角提供收费标准快捷入口。

字段必填说明
产品型号是选择器
期望服务时间是日期时间选择
上门地址是机器当前所在地
安装地址是机器移至的目的地
移机环境图片否最多 4 张,预判搬运环境
补充说明否120 字,是否有电梯/楼层层高

3.4 收费标准

城市分类A 类:北京、上海、广州、深圳;B 类:各省会城市及直辖市;C 类:其他城市。

维修收费 = 上门检测服务费 + 配件材料费

城市类别上门检测服务费配件材料费
A 类400 元价目明细可在瑞多 APP 查询
B 类300 元
C 类200 元

保修规则:符合保修条件免费;不符合按上表收费。上门检测服务费含市内交通费、拆装机工时费、故障排查工时费、仪表工具折旧;配件材料费含材料运费与更换工时费。

移机收费 = 机器拆装费 + 室外运输费

城市类别机器拆装费室外运输费
A 类400 元参考当地货运运营资费标准收取,可与客户协商
B 类300 元
C 类200 元

室内移机无室外运输费。温馨提示:移机前与安装好后,与客户确认产品外观与功能。

3.5 配件价格

展示常用配件名称、规格与参考价;底部固定声明:价格仅供参考,实际以工程师上门检测后的售后报价为准。

四、核心业务规则

  • 正常工单自动直达当地服务商,无需逐单审批;异常与改派由区域经理后台处理;
  • 保修判定在客服核实环节完成;
  • 收费按 A/B/C 城市分类,以服务地址所在区域为准;
  • 移机为有偿服务,下单页明确告知费用承担方;
  • 个人信息在记录列表中脱敏展示。

五、后续迭代(不在本期)

服务进度时间线与消息推送、在线支付、服务评价与回访、我的设备管理。

六、验收标准

  • 用户可在 3 步内完成一次报修提交;
  • 报修记录字段完整、脱敏正确;
  • 收费标准金额与城市分类和本文档完全一致,无保养标签;
  • 375px 宽度下无横向滚动、无错位。

V2 新增功能

  • 保修规则入口:首页新增保修规则说明卡片,方便用户快速了解保修政策;
  • 最近订单:首页展示最近工单,快速查看服务进度;
  • 服务进度追踪:新增进度页面,以时间线形式展示工单处理节点;
  • 状态标签:报修记录增加状态标签(维修中/已完成),一目了然;
  • 表单验证:手机号格式校验、必填项验证、字数统计优化;
  • 交互反馈:扫码模拟、图片上传预览、提交成功弹窗提示;
  • 空状态设计:无记录时展示友好提示与引导按钮。
